# Video Game Reselling Proof of Concept

A website that I had to create for a university project. The purpose of this website was to be able to resell game codes with information about each game. It has images and videos for each game with the homepage having it's custom built video player.

## How to use

To check out this website you have to download all of the repo and then open the home.html in google chrome.

## Techologies Used

I have used HTML, CSS and JS for this project. I have also used the media from the represented video games. It uses JS for the animation and the custom video player.

## Known limitations

There are a few videos that have not been uploaded to github due to the that they were too big. 
I am aware that the website is not finished but I have decided to leave it as it is to focus on different projects.
